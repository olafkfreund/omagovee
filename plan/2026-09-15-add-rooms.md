# Plan: Add new rooms and move lights between them reliably

Branch: `feat/add-rooms`. Intent approved in 383b4bb, spec in 65f6a26.

## Approved decisions (self-contained)

Data model unchanged: `~/.config/omagovee/rooms.json` is `{room: [Govee
device name, ...]}`. A device is in at most one room. Empty rooms do not
exist. All rules live in `bin/omarchy-govee`; `plugin/Govee.qml` only shells
out to it.

- **D1 Repair on load.** `load_rooms()` returns rooms with: a device kept
  only in the first room it appears in (file order), repeats within a room
  removed, rooms left empty dropped. In memory only; never writes on read.
  Reaches disk on the next room write.
- **D2 Reserved names.** New `check_room_name(name)` returns the stripped
  name, or dies if it is empty or one of `none`, `other`, `all`
  (case-insensitive). Used on the target of `rooms assign` (unless it is
  the literal `none`) and on the new name of `rooms rename`.
- **D3 `rooms <room> <dev>...` = `rooms assign <room> <dev>...`.** Resolves
  devices, moves them. No longer replaces the member list. `rooms none <dev>`
  unassigns.
- **D4 `assign_room` dedupes** its `names` argument, order kept.
- **D5 Rename onto an existing room is refused**, message
  `room 'X' already exists — move its lights with 'rooms assign'`. Scenes
  are not rewritten (unchanged, documented).
- **D6 `resolve(name)`:** exact case-insensitive match on Govee name, MAC or
  label wins; else substring matches (name or label, as today): one → it,
  several → die listing them, none → existing "No device matching" error.
  Applies to every command.
- **D7 Panel new-room field** under the room chips in a device's expanded
  controls: placeholder "New room…"; Enter → trim, if non-empty
  `act(["rooms", "assign", text, dev.name], "")`, clear, unfocus; bumps
  `root.editors` on focus like the other fields.
- **D8 Drop anywhere on a room.** Room delegate root becomes an `Item`
  holding the existing Column; the `DropArea` and its highlight `Rectangle`
  move out of the heading and fill the whole `Item`. `onDropped` body,
  drag handle, `preventStealing`, `Drag.*` and `z` raises unchanged. Heading
  still grows during a drag.
- **D9 Failure notifications.** `actionProc` collects stderr; in
  `onExited: function (code)` read the stderr text *before* `pump()`, and if
  `code !== 0` run
  `Quickshell.execDetached(["notify-send", "-u", "critical", "-a", "Omarchy",
  "Govee failed", text || "omarchy-govee failed"])`. Applies to all panel
  actions.

Out of scope: empty rooms, merge on rename, keying rooms by MAC, rewriting
scenes on rename, highlighting the `none` chip under "other".

**Live-CLI caveat.** `~/.local/bin/omarchy-govee` is a symlink to this
repo's `bin/omarchy-govee`, so the running bar uses the working tree as soon
as it is edited. Keep each CLI step runnable (run the tests after each), and
do not leave the branch checked out in a broken state. The plugin is a
copied directory (`~/.config/omarchy/plugins/olafkfreund.govee`) and changes
only when step 9 copies it.

2. **`bin/omarchy-govee` `load_rooms()`: D1.**

   ```python
   def load_rooms():
       """... first room wins; in memory only, so reading never writes."""
       seen, rooms = set(), {}
       for room, names in (read_json(rooms_path(), {}) or {}).items():
           kept = [n for n in dict.fromkeys(names) if n not in seen]
           seen.update(kept)
           if kept:
               rooms[room] = kept
       return rooms
   ```

4. **`check_room_name` + rename: D2, D5.** Add after `rooms_path()`:
   ```python
   RESERVED_ROOMS = ("none", "other", "all")

   def check_room_name(name):
       """`none` means no room, `other` is the panel's unassigned heading and
       `all` is a target keyword — a room with one of those names cannot be
       reached."""
       name = name.strip()
       if not name or name.lower() in RESERVED_ROOMS:
           die("Not a usable room name: %r (reserved: %s)"
               % (name, ", ".join(RESERVED_ROOMS)))
       return name
   ```

   `new = check_room_name(args[2])`; `if new in current: die("room %r
